===========================================

What this patcher does
----------------------
- Verifies the selected vanilla Virtual Families folder. It must hold
  Virtual Families.exe, Assets, Images, Sounds, fmod.dll, SDL2.dll, SDL2_image.dll,
  and Virtual Families.exe must be the official version 1.01.00
  (SHA-256 5db828c3f53c68696c18719aec0eb114be3fd4458ae2cbf185d8d4ef7eca4487).
- Creates a separate, clearly labeled modded game folder. The vanilla game folder is only read.
- With a vanilla folder selected, Enable/Disable Patches rebuilds a recognized modded folder from the
  vanilla folder. With only a modded folder selected, it reconfigures that folder in place.
- Backs up every file it will replace or delete before writing, and records every file it will create,
  so Restore Backup can put the folder back exactly.
- Writes machine-readable success/failure logs.
- Dry Run (Validate Only) checks the vanilla folder, the executable, the patch and the payload files,
  then stops before creating backups, creating the modded folder, or writing any game file.
- Payload files are read-only/copy-only: the patcher never writes into payload/.

What this patcher does not do
-----------------------------
- Does not inject code into a running game or edit process memory.
- Does not use obfuscation, packers, or admin-only install locations.
- Does not launch the game.
- Does not alter any save. The modded game keeps its own save folder.

The executable patch
--------------------
- The modded executable is the vanilla Virtual Families.exe plus two new sections:
  .vf1fun (read + execute), a small loader, and .vf1fud (read + write), its state.
  No page is both writable and executable.
- Two existing values change so the game enters the loader: the call at 0x4497e6 (end of the
  store screen's constructor) and theGame's Init vtable slot at 0x4b5e14. The PE checksum is
  updated. Nothing else in the original image changes.
- The loader loads "Virtual Families 1 Patcher Files\vf1fun.dll" by full path. If it is missing, the game runs
  exactly as normal.
- The modded executable is named "Virtual Families - Modded.exe". Its name never contains "patch": Windows treats
  such names as installers and asks for administrator rights.

Every file the patcher writes
-----------------------------
In the modded game folder (default "Virtual Families - Modded"):
- Every file of the vanilla folder except Virtual Families.exe, copied unchanged.
- Virtual Families - Modded.exe: the patched executable.
- Virtual Families 1 Patcher Files\vf1fun.dll: the patcher's DLL, copied from payload\vf1fun.dll.
- Virtual Families 1 Patcher Files\settings.ini: section [Patches], one Key=1/0 line per setting below.
  Other sections (written by the DLL, e.g. [Cheats] InterestRate) are kept as they were.
- .vf1_patch_backups\<date_time>_manifest\: one folder per run, holding vf1_patch_backup_manifest.json,
  files\... (copies of every file the run replaced or deleted), patch_log.json (or
  patch_error_log.json if the run failed) and, after a restore, restore_log.json.
Next to manifest.json (the patcher's own folder):
- patch_dry_run_log.json after a Dry Run, and patch_error_log.json when a run fails before its backup
  exists.
- patcher_local_settings.json: the folders you chose in the window, so they are filled in next time.
The patcher writes nothing else, and it never deletes a backup folder.

Written by the modded game itself
---------------------------------
- Virtual Families 1 Patcher Files\settings.ini: the DLL saves cheat values it remembers between sessions there.
- Saves: Documents\LDW\Virtual Families - Modded, separate from the vanilla game's
  Documents\LDW\Virtual Families.

Settings and defaults
---------------------
- Main Patches (green) and Optional Patches (black), as in the patcher window.
- FixVanillaGameBugs [on] (main): Fix Vanilla Game Bugs
  Keeps a brand-new family if the game is closed without quitting (the original game only saved before the adoption). In the Power Failure event, choosing to keep the food now says the food was not ok when people really get sick (the original game always said it was fine).
- OlderVillagerMortalityCurve [on] (main): Older Villager Mortality Curve
  Replaces only the yearly old-age death roll with the Virtual Families 2 patcher's calibrated curve, which accelerates past effective age 110. Active food groups still subtract 0-4 effective years. No hard maximum age (the original game's roll made death certain by about 75).
- PrivateRomanticTime [on] (main): Private Adult Romantic Time
  A married opposite-sex couple at six children can still have private romantic time when one is dropped on the other, with the stock cooldown (the original game refuses with "They have enough kids already!"). Same-sex couples already could. No baby is possible while the family is full.
- SpecialUpgrades [on] (main): Add visible mobile version purchases
  Special Upgrades in the Upgrades menu: Brokerage Account, Food Club, Health Plan and Lucky Rock, as in the Virtual Families 2 patcher, plus a Maid and a Gardener who keep the house and yard clean.
- CheatUpgrades [on] (optional): Cheat Upgrades
  Adds the Upgrades button's cheat pages: money, food, interest rate, villager cheats, store price multipliers, achievements and collections, house and yard mess, time controls (pause, speed, time warp), and the Family page (same-sex marriage, candidate reroll, divorce, pregnancy one-shots, new babies and adopted children, Adopt New Person after a game over, Evict Family).
- FleaMarket [on] (optional): Flea Market
  Every tray item the store sells, to buy or get for free.
- RollTheDice [on] (optional): Roll the Dice
  $500: an island event happens right away.

Restore
-------
- Restore Backup puts back the files a backup recorded, into the folder it was taken from, and deletes
  the files that run had created. It refuses to restore into the vanilla game folder.
