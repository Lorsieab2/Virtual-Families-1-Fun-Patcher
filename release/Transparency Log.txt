What this patcher does
----------------------
- Verifies the selected vanilla Virtual Families folder. It must hold
  Virtual Families.exe, Assets, Images, Sounds, fmod.dll, SDL2.dll, SDL2_image.dll,
  and Virtual Families.exe must be the official version 1.01.00
  (SHA-256 5db828c3f53c68696c18719aec0eb114be3fd4458ae2cbf185d8d4ef7eca4487).
- Creates a separate, clearly labeled modded game folder. The vanilla game folder is only read.
- With a vanilla folder selected, Enable/Disable Patches rebuilds a recognized modded folder from the
  vanilla folder. With only a modded folder selected, it reconfigures that folder in place.
- Backs up every file it will replace or delete before writing, and records every file it will create,
  so Restore Backup can put the folder back exactly.
- Writes machine-readable success/failure logs.
- Dry Run (Validate Only) checks the vanilla folder, the executable, the patch and the payload files,
  then stops before creating backups, creating the modded folder, or writing any game file.
- Payload files are read-only/copy-only: the patcher never writes into payload/.

What this patcher does not do
-----------------------------
- Does not inject code into a running game or edit process memory.
- Does not use obfuscation, packers, or admin-only install locations.
- Does not launch the game.
- Does not alter any save. The modded game keeps its own save folder.

The executable patch
--------------------
- The modded executable is the vanilla Virtual Families.exe plus two new sections:
  .vf1fun (read + execute), a small loader, and .vf1fud (read + write), its state.
  No page is both writable and executable.
- Two existing values change so the game enters the loader: the call at 0x4497e6 (end of the
  store screen's constructor) and theGame's Init vtable slot at 0x4b5e14. The PE checksum is
  updated. Nothing else in the original image changes.
- The loader loads "Virtual Families 1 Patcher Files\vf1fun.dll" by full path. If it is missing, the game runs
  exactly as normal.
- The modded executable is named "Virtual Families - Modded.exe". Its name never contains "patch": Windows treats
  such names as installers and asks for administrator rights.

Written by the modded game itself
---------------------------------
- Virtual Families 1 Patcher Files\settings.ini: the DLL saves cheat values it remembers between sessions there.
- Saves: Documents\LDW\Virtual Families - Modded, separate from the vanilla game's
  Documents\LDW\Virtual Families.

Settings and defaults
---------------------
- Main Patches (green) and Optional Patches (black), as in the patcher window.
- FixVanillaGameBugs [on] (main): Fix Vanilla Game Bugs
  Keeps a brand-new family if the game is closed without quitting (the original game only saved before the adoption). In the Power Failure event, choosing to keep the food now says the food was not ok when people really get sick (the original game always said it was fine). An age set by a cheat no longer becomes the Oldest Villager record: the record only rises when a villager ages into it.
- OlderVillagerMortalityCurve [on] (main): Older Villager Mortality Curve
  Replaces only the annual old-age death roll with a calibrated curve that accelerates past effective age 110. Active food groups still subtract 0-4 effective years. No hard maximum age.
- PrivateRomanticTime [on] (main): Private Adult Romantic Time
  A married opposite-sex couple at six children can still have private romantic time when one is dropped on the other (the original game refuses with "They have enough kids already!"). Like the Virtual Families 2 patcher, a couple that cannot conceive (same-sex, or six children) is also never made to wait "It is too soon to try to make a baby again" after an attempt, and the action reads "Having private adult romantic time". No baby is possible for them.
- AllowOlderPregnancies [on] (main): Allow Older Pregnancies
  Optional patch: preserves normal fertility behavior below age 50, then allows a small pregnancy chance when either parent is 50 or older. The older parent caps the chance from 10.0% at age 50 down to a permanent 0.1% floor at age 69+. Failed attempts involving an age-50+ parent do not start the stock try-for-baby cooldown. The stock Next Generation flow also becomes available when the oldest living person reaches age 60, provided there is a surviving child.
- ClampMoneyAndFood [on] (main): Clamp Max Money and Food
  Keeps coins at no more than 4,000,000,000 and food at no more than 2,147,483,647, the Virtual Families 2 patcher's maximums (the original game has no limit, and food wraps to a negative number past 2,147,483,647, which glitches the game).
- SpecialUpgrades [on] (main): Add visible mobile version purchases
  Special Upgrades in the Upgrades menu: Brokerage Account, Food Club, Health Plan and Lucky Rock, as in the Virtual Families 2 patcher, plus a Maid and a Gardener who keep the house and yard clean.
- CheatUpgrades [on] (optional): Cheat Upgrades
  Adds the Upgrades button's cheat pages: money, food, interest rate, villager cheats, store price multipliers, Anti-Spam Software ownership, achievements and collections, house and yard mess, time controls (pause; Slow, Normal and Fast as in Virtual Villagers, plus 5x and 10x; time warp), and the Family page (same-sex marriage, candidate reroll, divorce, pregnancy one-shots, spawned children, Adopt New Person after a game over, Evict Family), and a Clothing and Hairstyles page that shows every hairstyle and outfit and gives the one you click to a villager.
- FleaMarket [on] (optional): Flea Market
  Every tray item the store sells, to buy or get for free.
- RollTheDice [on] (optional): Roll the Dice
  $500: an island event happens right away.
- CustomMapImages [on] (optional): Custom Map/Game Images
  Replaces the standard house and some game images with customized ones. Credit to the original creators on LDWForums.
- VF2Songs [on] (optional): VF1 + VF2 Songs
  Adds VF2 songs in addition to the normal VF1 songs.
- GlowingCollectables [on] (optional): Glowing Collectables
  Makes the collectables in the yard glow, so they are easier to spot.
- BehaviorLabelVariants [on] (optional): Behavior Label Variants
  Varies the caption shown for a villager's action, using the Virtual Families 2 patcher's own captions: Watching TV, Reading, Browsing the web, Playing video games, Playing a board game, Doing homework and taking an online test, the sandbox, watering the flower boxes, Taking a nap (dreams), Needs to sit down, Enjoying the patio, the pool, Taking a shower, Getting a drink, Looking for snacks, Preparing a meal, Heating up some food, Making coffee and lattes, washing and grooming at the bathroom sink, stargazing, career work at the computer, kitchen and workshop, and "Having private adult romantic time" for a couple that cannot conceive. Age-appropriate, as in VF2: online shopping from 13, social media, teen games and teen homework from 14, child pool games and homework for younger villagers, bath toys for children and spa days from 14, jewelry for girls and women from 14. At the computer, browsing the web and playing video games are chosen 50:50, as in VF2: a villager dropped on the computer flips a coin, and a villager choosing by itself picks the two equally often while using the computer as often as in the original game (nothing in the save is changed). Apart from that, the behaviors, their chances and career progression are not changed.

Restore
-------
- Restore Backup puts back the files a backup recorded, into the folder it was taken from, and deletes
  the files that run had created. It refuses to restore into the vanilla game folder.
