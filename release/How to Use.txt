Virtual Families 1 Fun Patcher - How to Use
=======================================

ELI5 version:
This patcher makes a separate modded copy of your official Virtual Families
folder. It checks that your original game folder looks correct before it
changes anything.

Check for updates:
https://github.com/Lorsieab2/Virtual-Families-1-Patcher/

Fix Vanilla Game Bugs (on by default): in the original game, a brand-new
family was lost if the game was closed any way other than Quit (for example a
crash or Task Manager) before its next autosave, which comes every 10 minutes.
It came back as "All of your little family members died": the game's last
save was from before the adoption. The patched game saves right after you
adopt, so the new family is kept. The same applies after Start Over
and Next Generation. Quitting through the menu is still the best way to keep
everything since then.

The same setting fixes the Power Failure event: choosing to keep the food
always said "This stuff still looks okay" even when people got sick. Now the
words match what happens ("Everyone gets an upset stomach. The food was not
ok.").

It also fixes the store's Pet Turtle: the original game checked whether the
family had a dog instead of a turtle, so a family with a dog was never offered
the turtle (and a family with a turtle still was). Now the turtle is offered
whenever the family has no turtle.

How to patch
------------
1. Install the official Virtual Families PC version (1.01.00).

2. Unzip this patcher package anywhere you like.

3. You need Python 3.9 or newer (python.org). Keep the "tcl/tk and IDLE"
   component ticked when installing.

4. Run:
   Launch_GUI.bat

   The BAT file is the supported launcher. It resolves files relative to the
   folder where you extracted this ZIP. The patcher's own files are in the
   "Virtual Families 1 Fun Patcher Files" folder next to it: leave that
   folder where it is.

5. The patcher should auto-load manifest.json (from the "Virtual Families 1
   Fun Patcher Files" folder).

6. Select your vanilla Virtual Families install folder. It should be the
   folder that contains Virtual Families.exe, Images, Sounds, Assets, and the
   required DLL files.

7. Review the patch checkboxes. Every patch says what it does under its
   name; a patch that needs another one says so in bold.

8. Optional but recommended: click Dry Run (Validate Only).
   Dry Run validates that the patcher's working. It does not actually
   change/write files.

9. Click Enable/Disable Patches. If you uncheck a patch later, click this
   button again to rebuild the modded folder from vanilla with that patch
   disabled. To change the patches without the vanilla folder, clear the
   vanilla folder box and choose your modded folder as the Modded output
   folder: the patcher then only switches the patches in that folder.

10. The patcher creates or refreshes a separate modded folder next to your
    vanilla game folder ("Virtual Families - Modded"). If your game is
    installed under Program Files, the modded folder goes in your own Games
    folder instead, because Windows needs administrator rights to create a
    folder there. Your original game folder and original saves are left
    alone.

11. Run "Virtual Families - Modded.exe" inside the new modded folder.

Prefer a console window? Apply_<version>_Patcher.bat does the same with every
patch at its default: enter or drag the original "Virtual Families.exe" into
it. It needs Python too.

Restore a backup
----------------
Every Enable/Disable Patches run first backs up the files it will change, in
a new folder under ".vf1_patch_backups" inside the modded folder. Choose one
of those folders under "Restore backup" and click Restore Backup to put the
modded folder back the way it was before that run.

Tools tab: Back Up Saves / Restore Saves
----------------------------------------
Next to the Patches tab is a Tools tab for your family saves.

  Back Up Saves     Tick the save folders (the modded game's own one is ticked
                    for you) and click Back Up Selected. Everything in the
                    save folder (your slot saves and the patcher's own files
                    for each save) is copied into a new dated folder,
                    "Backups\Backup <date and time>", inside that save folder.
                    The game can stay open: it is paused for the copy, but the
                    backup holds the family as of its last save: the game
                    saves by itself every 10 minutes while it runs, and when
                    you quit normally. Old backups are never replaced or
                    deleted. Game speed is set to Paused in the backup's
                    family saves (your own saves are unchanged), so a
                    restored backup opens paused and never catches up on
                    the time since it was made.
  Restore Saves     Quit the game first. Choose a backup, choose the whole
                    folder or one save slot, and click Restore. You are shown
                    which files will change and asked to confirm. Your saves as
                    they are now are backed up first (as "Backup <date>
                    (before restore)"), so a restore can be undone.
                    Delete Backup removes a backup you no longer want.
  Game Speed        Quit the game first. Pick a save (each shows its speed
                    now) and choose Paused or Normal. Paused works as if you
                    paused just before the game last saved; Normal as if you
                    unpaused it right now, so the paused time is never aged
                    in. Your saves are backed up first (as "Backup <date>
                    (before speed change)"). Time Controls' Slow, Fast, 5x
                    and 10x are not offered: the game never keeps them in a
                    save and loads every family at Normal or Paused.
  Game Mechanics    Shows how the game works underneath: ageing, time
                    away, needs, health, sickness, old age, babies,
                    careers, money, events, messes, collectibles and
                    malfunctions, with every chance and timer. Times are
                    real times at Normal, with Slow and Fast beside them.
                    Each line says how sure it is: VERIFIED-E (the game's
                    own code was run), VERIFIED-C (read in the game's own
                    code) or UNCONFIRMED. It only reads: nothing is opened
                    or changed, so the game can stay open.

Every button and every patch has a small "?" beside it with a short guide.
Back up your saves before trying the Experimental patch (Up to 28 Children).

Existing saves:
Vanilla Virtual Families saves are compatible with the modded version!
The modded game uses its own save folder under Documents/LDW using the modded
EXE name ("Virtual Families - Modded"). To play existing saves in the modded
game, copy the contents of your original Documents/LDW/Virtual Families save
folder into the modded save folder shown after patching.

If no valid install is detected:
Make sure you selected the official Virtual Families install folder, not a
partial folder, an already-modded folder, or the patcher folder itself.
