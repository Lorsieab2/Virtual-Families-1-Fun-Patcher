Virtual Families 1 Fun Patcher - How to Use
=======================================

ELI5 version:
This patcher makes a separate modded copy of your official Virtual Families
folder. It checks that your original game folder looks correct before it
changes anything.

Check for updates:
https://github.com/Lorsieab2/Virtual-Families-1-Patcher/

Fix Vanilla Game Bugs (on by default): in the original game, a brand-new
family was lost if the game was closed any way other than Quit (for example a
crash or Task Manager) before its next autosave, which comes every 10 minutes.
It came back as "All of your little family members died": the game's last
save was from before the adoption. The patched game saves right after you
adopt, so the new family is kept. The same applies after Start Over
and Next Generation. Quitting through the menu is still the best way to keep
everything since then.

The same setting fixes the Power Failure event: choosing to keep the food
always said "This stuff still looks okay" even when people got sick. Now the
words match what happens ("Everyone gets an upset stomach. The food was not
ok.").

It also fixes the store's Pet Turtle: the original game checked whether the
family had a dog instead of a turtle, so a family with a dog was never offered
the turtle (and a family with a turtle still was). Now the turtle is offered
whenever the family has no turtle.

And it fixes the outfits in the item tray: in the original game every Male
Outfit in the tray (and every Female Outfit) showed the picture of the last
one bought, and putting any of them on gave that last one. Now each outfit
keeps the picture it had in the store when you bought it, and putting it on
gives that outfit. The pictures are kept in the patcher's own file beside
each save ("Virtual Families 1 Patcher Data\Outfits"); the save itself is not
changed, and outfits bought before the fix keep the game's own picture.

It also stops the Bank from closing the game: in the original game, a family
with $0.42 or less whose members earn no pay crashed the game the moment the
Bank button was clicked (its "Next 7 Days" chart divided by zero). Now the
chart's bars are simply empty; every other chart looks exactly as before.

R Refreshes the Store (on by default): in the store, press R (small r or
capital R) to redraw the store's Flea Market, its six random items (the
game's code calls them the specials), and the random Male Outfit and Female
Outfit pictures. It works every time you press it, using the game's own draw
and odds. The original game has the same hidden key, but only a small r and
only once more than 1 hour of real time has passed since the last draw. The
half-price grocery, the other items and prices, and every outfit you already
bought (it keeps its picture) stay as they are. R does nothing on any other
screen, and nothing in the Upgrades menu's Flea Market page, which already
lists every tray item at once. R works the same with the Flea Market page and
Free and Guaranteed Cheats on or off.

Render Unicode with In-Game Fonts (on by default): the game takes and shows
any letter: accents (French, German, Spanish, Turkish, Polish, Vietnamese...),
Greek, Cyrillic, Japanese, Chinese, Korean, Cuneiform, emoji and more. Type
them in the game's own name boxes with your keyboard's accent keys, Alt codes
or an input method; Backspace deletes a whole letter. Letters the game's fonts
lack are made in the same style: accented ones from the game's own letters and
accents, the rest drawn by Windows in the font's size. Names stay in the
save's own name spaces; a letter beyond A to Z uses 2 to 4 places of the room,
so a family name holds 19 plain letters but fewer accented ones. Without the
patch (or in the original game) the save still loads and works, but an
accented letter shows as two or three odd letters (Zoe with two dots shows as
"ZoÃ«"). Not yet tested in a running game.

Use Unicode Font (overrides in-game fonts) (off by default; Owner's Defaults
leaves it off): the game's text is drawn in a font you choose instead of its own
letters, in any language. Pick the font with Unicode Font... on the Tools
tab (any installed font or a .ttf/.otf file; Segoe UI if you pick none).
Each text size keeps its height and colour and is sized so a line is as wide
as before. It cannot be on with Render Unicode with In-Game Fonts: ticking
one unticks the other. Typing and names work the same with either.

How to patch
------------
1. Install the official Virtual Families PC version (1.01.00).

2. Unzip this patcher package anywhere you like.

3. You need Python 3.9 or newer (python.org). Keep the "tcl/tk and IDLE"
   component ticked when installing.

4. Run:
   Launch_GUI.bat

   The BAT file is the supported launcher. It resolves files relative to the
   folder where you extracted this ZIP. The patcher's own files are in the
   "Virtual Families 1 Fun Patcher Files" folder next to it: leave that
   folder where it is.

5. The patcher should auto-load manifest.json (from the "Virtual Families 1
   Fun Patcher Files" folder).

6. Select your vanilla Virtual Families install folder. It should be the
   folder that contains Virtual Families.exe, Images, Sounds, Assets, and the
   required DLL files.

7. Review the patch checkboxes. Every patch says what it does under its
   name; a patch that needs another one says so in bold. The preset
   buttons tick a whole set at once:
     Select All Patches    every patch except the Experimental ones.
     Default Patches       the defaults: every patch except Cheat Upgrades,
                           Flea Market, Free and Guaranteed Cheats and Up to
                           28 Children.
     Owner's Defaults      the patcher owner's own choice: every patch except
                           Up to 28 Children and Use Unicode Font
                           (Render Unicode with In-Game Fonts is on).
     Deselect All Patches  nothing.
   Patch Selection Settings... opens a list of every patch with a search
   box: tick the ones you want and press Tick These or Untick These.

8. Optional but recommended: click Dry Run (Validate Only).
   Dry Run validates that the patcher's working. It does not actually
   change/write files.

9. Click Enable/Disable Patches. If you uncheck a patch later, click this
   button again to rebuild the modded folder from vanilla with that patch
   disabled. To change the patches without the vanilla folder, clear the
   vanilla folder box and choose your modded folder as the Modded output
   folder: the patcher then only switches the patches in that folder.

10. The patcher creates or refreshes a separate modded folder next to your
    vanilla game folder ("Virtual Families - Modded"). If your game is
    installed under Program Files, the modded folder goes in your own Games
    folder instead, because Windows needs administrator rights to create a
    folder there. Your original game folder and original saves are left
    alone.

11. Run "Virtual Families - Modded.exe" inside the new modded folder.

Prefer a console window? Apply_<version>_Patcher.bat does the same with every
patch at its default: enter or drag the original "Virtual Families.exe" into
it. It needs Python too.

Restore a backup
----------------
Every Enable/Disable Patches run first backs up the files it will change, in
a new folder under ".vf1_patch_backups" inside the modded folder. Choose one
of those folders under "Restore backup" and click Restore Backup to put the
modded folder back the way it was before that run.

Tools tab: Back Up Saves / Restore Saves
----------------------------------------
Next to the Patches tab is a Tools tab for your family saves.

  Back Up Saves     Tick the save folders (the modded game's own one is ticked
                    for you) and click Back Up Selected. Everything in the
                    save folder (your slot saves and the patcher's own files
                    for each save) is copied into a new dated folder,
                    "Backups\Backup <date and time>", inside that save folder.
                    The game can stay open: it is paused for the copy, but the
                    backup holds the family as of its last save: the game
                    saves by itself every 10 minutes while it runs, and when
                    you quit normally. Old backups are never replaced or
                    deleted. Game speed is set to Paused in the backup's
                    family saves (your own saves are unchanged), so a
                    restored backup opens paused and never catches up on
                    the time since it was made.
  Restore Saves     Quit the game first. Choose a backup, choose the whole
                    folder or one save slot, and click Restore. You are shown
                    which files will change and asked to confirm. Your saves as
                    they are now are backed up first (as "Backup <date>
                    (before restore)"), so a restore can be undone.
                    Delete Backup removes a backup you no longer want.
  Copy Player Slot  Quit the game first. Pick a family, a save slot and
                    a new name (1 to 300 characters), then Copy.
                    It asks first (Yes / No; Return or Escape mean No).
                    The family is copied into that slot with everything
                    the patcher keeps for it (its Family History log,
                    Family Tree, extra children and outfit pictures); the
                    family you copied is not changed. Your saves are
                    backed up first (as "Backup <date> (before copy)").
                    A slot with no save file is empty, even if the game's
                    menu still showed a name for it. Picking a slot that
                    holds a family replaces that family (it asks first).
                    The old family's files, or anything a deleted family
                    left, are moved into Backups ("Replaced by copy
                    <date> - Save <N> - <old name>"), never deleted.
  Game Speed        Quit the game first. Pick a save (each shows its speed
                    now) and choose Paused or Normal. Paused works as if you
                    paused just before the game last saved; Normal as if you
                    unpaused it right now, so the paused time is never aged
                    in. Your saves are backed up first (as "Backup <date>
                    (before speed change)"). Time Controls' Slow, Fast, 5x
                    and 10x are not offered: the game never keeps them in a
                    save and loads every family at Normal or Paused.
  Game Mechanics    Shows how the game works underneath: ageing, time
                    away, needs, health, sickness, old age, babies,
                    careers, money, events, messes, collectibles and
                    malfunctions, with every chance and timer. Times are
                    real times at Normal, with Slow and Fast beside them.
                    Each line says how sure it is: VERIFIED-E (the game's
                    own code was run), VERIFIED-C (read in the game's own
                    code) or UNCONFIRMED. It only reads: nothing is opened
                    or changed, so the game can stay open.
  Picture Maker     Draws your family exactly as the game draws them and
                    saves the pictures as PNGs with a clear background.
                    Pick the game folder (its own pictures are used; none
                    ship with the patcher), then:
                    From my save: pick the save folder and the family;
                    click anyone to see them as they look now (age, hair
                    and face, outfit, a baby on the way), in the house in
                    any pose, or as the big portrait of the Adoption and
                    Dating screens. The outfits in the store and the tool
                    tray are listed too (with Fix Vanilla Game Bugs each
                    tray outfit keeps its own picture, as in the game).
                    Make your own: pick gender, age (each year under 14 is
                    drawn smaller; from 45 the older hair pictures),
                    hair and face 0-49, outfit 0-49, pose, direction, head
                    turn, babies on the way, something carried, shadow,
                    ghost, and the game folder's, the stock or the
                    patcher's own pictures.
                    Every picture: every picture the game has, drawn as
                    the game draws it, sorted into categories (meters and
                    bars, buttons, dialogs, icons, fonts, house and yard,
                    furniture, food, weather and night, effects, animals,
                    people, store, collectibles, screens, the patcher's
                    own): every sprite sheet whole and every cell and
                    animation frame, buttons in each state, the bars
                    empty and at their levels with frame and fill joined,
                    dialogs tiled at the game's sizes, every font glyph,
                    each room at each Home Improvement level, night.
                    Find searches; Show picks used, unused or not-checked
                    pictures. "(unused)" says why the game never shows it.
                    Save PNG: the game's size, 2x, 4x or your own width
                    and height, with or without a small margin (Every
                    picture can keep a picture's whole size). Save all
                    puts each picture in a folder for its category. Saves
                    and game files are only read.
  Game Text         Type anything and see it exactly as the game draws its
                    text, in any of the game's fonts and any colour, then
                    save it as a PNG with a clear background (the game's
                    size, 2x, 4x or your own). Pick accents and any other
                    character from the list: search by name ("e acute") or
                    code (U+00E9). Each says if the font has it, if the
                    patcher made it in the font's style (patcher-made, shown
                    in the game too), or if Windows draws it. Fonts marked
                    unused are in the game folder but never shown by the
                    game. Only the game folder is read.
  Unicode Font      Chooses the font Use Unicode Font draws the game's
                    text with: pick the modded game folder, then a font
                    from the list or a font file. The preview shows the
                    game's four text sizes as the game will draw them.
                    Save; the game uses it from its next start.

Every button and every patch has a small "?" beside it with a short guide.
Back up your saves before trying the Experimental patch (Up to 28 Children).

Existing saves:
Vanilla Virtual Families saves are compatible with the modded version!
The modded game uses its own save folder under Documents/LDW using the modded
EXE name ("Virtual Families - Modded"). To play existing saves in the modded
game, copy the contents of your original Documents/LDW/Virtual Families save
folder into the modded save folder shown after patching.

If no valid install is detected:
Make sure you selected the official Virtual Families install folder, not a
partial folder, an already-modded folder, or the patcher folder itself.
